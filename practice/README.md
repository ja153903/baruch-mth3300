# Practice problems

These problems are ungraded. Each topic folder has a starter file and tests:

```sh
uv run pytest practice/strings        # one topic
uv run pytest practice -x             # everything, stopping at the first failure
```

**Exam prep tip:** the midterm and final are **no AI**, so work these problems without AI help first. Once you've passed the tests, ask an AI to review your solution and suggest a cleaner one, and make sure you can explain any difference.
